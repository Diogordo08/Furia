## Sobre o projeto

Um sistema conversacional em tempo real para fãs da FURIA Esports, integrado com resultados de jogos usando a API da PandaScore. O chat permite que usuários enviem mensagens e emojis enquanto consultam os resultados mais recentes da equipe FURIA.
